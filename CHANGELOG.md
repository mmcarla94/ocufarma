# Changelog OcuFarma 1.2.0

## Nuove funzionalità

### Sistema di autenticazione avanzato
- Aggiunta selezione del ruolo (medico o paziente) durante la registrazione
- Visualizzazione del ruolo utente nella sezione profilo
- Rimosso il pulsante "Utilizza credenziali demo" dalla pagina di login
- Implementato sistema completo di registrazione con conferma email
- Aggiunta funzionalità di reset password

### Sistema di notifiche avanzato
- Implementate notifiche per i farmaci agli orari specifici
- Aggiunta possibilità di segnare le terapie come "completate", "posticipate" o "non instillate"
- Integrazione con il calendario per visualizzare lo stato delle terapie con codice colore
- Aggiunta pagina "Aderenza alla terapia" nella sezione profilo

### Miglioramenti generali
- Aggiunto Stanislao Rizzo come sviluppatore nella sezione info
- Implementata funzionalità di contatto email nella sezione info
- Migliorata la lettura dei barcode con collegamento diretto alla pagina del farmaco

## Correzioni di bug
- Risolti problemi con il sistema di notifiche
- Corretti errori di visualizzazione nella sezione info
- Migliorata la stabilità generale dell'applicazione
